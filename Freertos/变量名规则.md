## FreeRTOS 常见变量前缀

| 前缀    | 含义                                 | 示例                      |
| ----- | ---------------------------------- | ----------------------- |
| `v`   | void，通常用于无返回值函数                    | `vTaskDelay()`          |
| `p`   | Pointer，指针                         | 通常与其他前缀组合               |
| `pv`  | `void *` 指针                        | `pvOwner`               |
| `px`  | 指向复合类型的指针                          | `pxList`                |
| `x`   | 常用于 FreeRTOS 自定义类型的变量，也用于部分返回状态的函数 | `xItemValue`            |
| `ux`  | 无符号整数类型                            | `uxNumberOfItems`       |
| `pc`  | `char *` 指针                        | `pcTaskName`（注意实际可能是数组） |
| `puc` | `unsigned char *` 指针               | `pucBuffer`             |
| `uc`  | `unsigned char`                    | `ucQueueType`           |
| `c`   | `char`                             | `cRxLock`               |
| `ul`  | `unsigned long`                    | `ulValue`               |
| `us`  | `unsigned short`                   | `usValue`               |
| `s`   | `short`                            | `sValue`                |
| `pd`  | 常见于历史接口和宏命名                        | `pdTRUE`、`pdFALSE`      |

其中，`x` 的含义比较宽泛，不能简单理解为某一种固定 C 类型。
