FreeRTOS 的 Mutex 支持优先级继承（Priority Inheritance Protocol，PIP）。

其核心思想是：

> 当高优先级任务等待低优先级任务持有的互斥量时，让低优先级任务临时继承高优先级任务的优先级。

### 1. 原始优先级

```
TaskH：5
TaskM：3
TaskL：1
```

TaskL 获取 Mutex 后，TaskH 尝试获取同一个 Mutex。

此时 FreeRTOS 发现：

```
TaskH.uxPriority > TaskL.uxPriority
```

于是可以调用：

```
xTaskPriorityInherit();
```

将 TaskL 的当前优先级临时提升到 5。

```
TaskH：5（Blocked）
TaskM：3（Ready）
TaskL：5（Ready）
```

这时 TaskM 无法再凭借优先级 3 抢占 TaskL。

TaskL 能继续执行，尽快释放 Mutex。

### 2. 时间线

```
时间 ─────────────────────────────────────►

TaskH        [等待 Mutex.....][运行────────]
TaskM
TaskL   [运行][继承优先级 5][释放]
```

完整流程：

```
TaskL 获取 Mutex
        │
        ▼
TaskH 尝试获取 Mutex
        │
        ▼
TaskH 进入阻塞状态
        │
        ▼
TaskL 继承 TaskH 的优先级 5
        │
        ▼
TaskL 继续执行
        │
        ▼
TaskL 释放 Mutex
        │
        ├── 处理继承优先级的恢复
        │
        └── 唤醒 TaskH
                 │
                 ▼
         TaskH 重新尝试获取 Mutex
```

对于 FreeRTOS，涉及的核心函数有：

```
xTaskPriorityInherit();
xTaskPriorityDisinherit();
```

需要注意：**优先级继承不能消除所有阻塞，它主要消除中优先级任务造成的额外延迟。**

高优先级任务仍然需要等待低优先级任务完成已经进入的临界区。
