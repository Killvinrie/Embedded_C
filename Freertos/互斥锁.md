前面介绍的临界区适合保护执行时间非常短的代码。

但如果多个任务要访问同一个外设，例如 UART，怎么办？

假设两个任务都要通过串口打印数据：

```c
void Task1(void *arg)
{
    HAL_UART_Transmit(&huart1, data1, 10, 100);
}

void Task2(void *arg)
{
    HAL_UART_Transmit(&huart1, data2, 10, 100);
}
```

如果任务切换发生在串口发送过程中，且底层驱动没有提供充分的并发保护，就可能出现串口状态冲突、发送失败等问题。

为了解决这个问题，可以使用互斥锁。

## 4.1 互斥锁的工作原理

你可以把互斥锁理解成一把钥匙。

```
              UART 外设
                  │
                🔒
                  │
          ┌───────┴───────┐
          │               │
        Task1           Task2
          │               │
       获取锁           等待锁
          │               │
       使用 UART           │
          │               │
       释放锁              │
          │               │
          └──────────────►│
                       获取锁
                          │
                       使用 UART
                          │
                       释放锁
```

在任何时刻，只有持有锁的任务能够访问被保护的资源。

## 4.2 FreeRTOS 代码示例

```c
#include "FreeRTOS.h"
#include "task.h"
#include "semphr.h"

SemaphoreHandle_t uartMutex;

void Task1(void *argument)
{
    while (1)
    {
        if (xSemaphoreTake(uartMutex, portMAX_DELAY) == pdTRUE)
        {
            HAL_UART_Transmit(
                &huart1,
                (uint8_t *)"Task1\r\n",
                7,
                100
            );

            xSemaphoreGive(uartMutex);
        }

        vTaskDelay(pdMS_TO_TICKS(100));
    }
}

void Task2(void *argument)
{
    while (1)
    {
        if (xSemaphoreTake(uartMutex, portMAX_DELAY) == pdTRUE)
        {
            HAL_UART_Transmit(
                &huart1,
                (uint8_t *)"Task2\r\n",
                7,
                100
            );

            xSemaphoreGive(uartMutex);
        }

        vTaskDelay(pdMS_TO_TICKS(100));
    }
}
```

在启动调度器之前创建锁：

```c
int main(void)
{
    HAL_Init();
    SystemClock_Config();

    uartMutex = xSemaphoreCreateMutex();

    if (uartMutex == NULL)
    {
        Error_Handler();
    }

    xTaskCreate(Task1, "Task1", 256, NULL, 2, NULL);
    xTaskCreate(Task2, "Task2", 256, NULL, 2, NULL);

    vTaskStartScheduler();

    while (1);
}
```

这里需要理解两个 API。

**获取互斥锁：**

```c
xSemaphoreTake(uartMutex, portMAX_DELAY);
```

- 如果锁未被其他任务占有，就获取成功。
- 如果锁已被占用，当前任务可以进入阻塞状态等待。
- `portMAX_DELAY` 是否代表无限等待，还与 FreeRTOS 的配置有关。

**释放互斥锁：**

```c
xSemaphoreGive(uartMutex);
```

当前任务使用完 UART 后，释放锁，让其他任务有机会获取。

需要注意，互斥锁保护的是应用层的访问顺序。如果使用 DMA 异步发送，启动 DMA 后立即释放锁通常还不够，还必须保证发送缓冲区在传输完成前有效，并正确管理外设的忙碌状态。
