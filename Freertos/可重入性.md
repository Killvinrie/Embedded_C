### 可重入性（Reentrancy）

一个函数在尚未执行完成时，又被另一个执行流调用，如果两次执行不会相互破坏状态，就具有可重入性。

例如：

```c
int add(int a, int b)
{
    int result = a + b;
    return result;
}
```

这个函数没有使用可变的共享状态，因此是可重入的。

但下面这个函数：

```c
int func(void)
{
    static int count = 0;

    count++;

    return count;
}
```

由于使用了静态变量 `count`，当多个任务并发调用时，会产生共享状态竞争，因此不具有通常意义上的可重入性。
