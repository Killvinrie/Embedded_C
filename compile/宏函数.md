利用[[三元运算符]]构建基础数学宏函数
```c

#define MAX(a, b) (((a) > (b)) ? (a) : (b))

#define MIN(a, b) (((a) < (b)) ? (a) : (b))

#define ABS(x) (((x) < 0) ? -(x) : (x))
```

利用
```c
do {}while(0) 
```
来避免对原代码产生影响
```c
#define DOSOMETHING() \
        do{ \
          foo1();\
          foo2();\
        }while(0)\
```

由于编程习惯在语句最后加封号，因此宏的最后不需要封号;
```c
if(1)
	DOSOMETHING();
```
